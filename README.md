# 🎵 Discord Music Bot
Простой и функциональный музыкальный бот для Discord с поддержкой YouTube, очередью воспроизведения и удобными командами управления.

## ✨ Возможности

* **Воспроизведение музыки** из YouTube по ссылке или поиску
* **Очередь воспроизведения** с возможностью добавления нескольких треков
* **Режимы повтора**
  * 🔂 Повтор текущего трека
  * 🔁 Повтор всей очереди
* **Управление воспроизведением:**
  * ⏯️ Пропуск трека
  * ⏮️ Возврат к предыдущему треку
  * ⏹️ Остановка
* **История воспроизведения** - возможность вернуться к прослушанным трекам
* **Автоматическое восстановление ссылки** на поток при необходимости

## 🌐 Многоязычная поддержка

Бот поддерживает несколько языков. Язык можно выбрать для каждого сервера отдельно.

**Доступные языки:**
-  Английский (English)
-  Русский (Русский)

**Команды для управления языком:**
- `/language` - выбрать язык для сервера
- `/lang` - показать текущий язык сервера

Язык сохраняется автоматически и используется для всех команд бота.

## 🚀 Команды

### Основные команды
| Команда | Описание | Пример |
|---------|----------|--------|
| `/join` | Подключение бота к вашему голосовому каналу | `/join` |
| `/leave` | Отключение бота от голосового канала | `/leave` |
| `/play [url]` | Добавление трека по ссылке YouTube | `/play https://youtu.be/...` |
| `/search [title]` | Поиск и добавление трека по названию | `/search never gonna give you up` |
| `/skip` | Пропуск текущего трека | `/skip` |
| `/back` | Возврат к предыдущему треку | `/back` |
| `/stop` | Остановка воспроизведения | `/stop` |
| `/repeat_one` | Включение/отключение повтора текущего трека | `/repeat_one` |
| `/repeat_all` | Включение/отключение повтора текущей очереди | `/repeat_all` |
| `/ping` | Проверка задержки бота | `/ping` |
| `/queue` | Показывает текущую очередь и текущий трек | `/queue` |
| `/history` | Показывает историю и текущий трек | `/history` |
| `/language` | Позволяет выбрать язык для сервера | `/language Русский` |
| `/lang` | Показывает текущий язык сервера | `/lang` |

## 📋 Требования
* Python 3.8 или выше
* FFmpeg
* Токен Discord бота
* yt-dlp

## 🔧 Установка

### 1. Клонирование репозитория
``` bash
git clone https://github.com/Progress-ux/DiscordBotPy.git
cd DiscordBotPy
```
### 2. Установка зависимостей
``` bash
pip install -r requirements.txt
```
### 3. Установка FFmpeg

#### Windows:
* Скачайте FFmpeg с [официального сайта](https://ffmpeg.org/download.html)
* Добавьте путь к FFmpeg в переменную окружения PATH

#### Linux (Ubuntu/Debian):
``` bash
sudo apt update
sudo apt install ffmpeg
```

#### macOS:
``` bash
brew install ffmpeg
```

### 4. Настройка бота
Создайте файл `.env` в корневой директории проекта:

``` env
TOKEN=ваш_токен_бота_здесь
```

### 5. Запуск бота

``` bash
python main.py
```

## ⚙️ Конфигурация
### Основные настройки в `handler/config.py`:
* **YDL_OPTIONS** - настройки для yt-dlp при работе с ссылками
* **YDL_OPTIONS_FROM_TITLE** - настройки для поиска по названию
* **FFMPEG_OPTIONS** - параметры FFmpeg для стриминга

## 🛠️ Технические детали
* Асинхронная архитектура на базе `discord.py`
* Управление состоянием через флаги (`stop_flag`, `skip_flag`, `back_flag`)
* Автоматическое восстановление потока при проблемах с соединением
* Поддержка нескольких серверов - отдельный экземпляр `MusicHandler` для каждого гильдии

## 🔍 Особенности реализации

### MusicHandler
* Управляет воспроизведением для конкретного сервера
* Обрабатывает флаги управления (стоп, скип, назад)
* Поддерживает цикл воспроизведения

### QueueManager

* Управляет очередью треков
* Хранит историю воспроизведения
* Реализует режимы повтора

### Track
* Хранит информацию о треке (название, автор, длительность)
* Управляет ссылками на поток

## 🐛 Решение проблем

### Проблемы с YouTube
* yt-dlp может требовать обновления: `pip install -U yt-dlp`
* Проверьте настройки в `config.py`

### Бот не подключается к голосовому каналу
* Убедитесь, что у бота есть права на подключение к голосовым каналам
* Проверьте токен в файле `.env`
