# Discord Music Bot

Музыкальный бот для Discord на Python с поддержкой протокола сквозного шифрования голосовых каналов Discord (DAVE E2EE), очередями, плейлистами и интерактивными кнопками управления.

## Возможности

- Воспроизведение треков и плейлистов по прямой ссылке или поисковому запросу
- Поддержка актуального протокола Discord DAVE E2EE (голос воспроизводится без сбоев)
- Интерактивные кнопки управления под сообщением трека (Пауза/Пуск, Пропуск, Стоп)
- Полное управление очередью: просмотр (`/queue`), перемешивание (`/shuffle`), очистка (`/clear`), удаление треков (`/remove`)
- Контроль звука: регулировка громкости (`/volume`), перемотка (`/seek`), пауза (`/pause`) и возобновление (`/resume`)
- Отображение текущего трека с прогресс-баром (`/nowplaying`, `/np`)
- Режимы повтора: текущий трек (`/repeat_one`) или вся очередь (`/repeat_all`)
- История прослушанных треков и возврат назад (`/back`)
- Автоматический тайм-аут простоя (отключение при неактивности или из пустого канала)
- Готовый запуск в один клик через `run.bat`

## Список команд

| Команда | Описание | Пример |
|---|---|---|
| `/play <query>` | Воспроизвести трек, плейлист или найти по названию | `/play https://www.youtube.com/...` |
| `/search <title>` | Поиск и добавление трека по названию | `/search daft punk get lucky` |
| `/pause` | Приостановить воспроизведение | `/pause` |
| `/resume` | Возобновить воспроизведение | `/resume` |
| `/stop` | Остановить воспроизведение и сбросить очередь | `/stop` |
| `/skip` | Пропустить текущий трек | `/skip` |
| `/back` | Вернуться к предыдущему треку | `/back` |
| `/nowplaying` (`/np`) | Текущий трек и прогресс-бар | `/nowplaying` |
| `/queue` | Показать текущую очередь воспроизведения | `/queue` |
| `/history` | Показать историю треков | `/history` |
| `/shuffle` | Перемешать треки в очереди | `/shuffle` |
| `/clear` | Очистить очередь | `/clear` |
| `/remove <index>` | Удалить трек из очереди по индексу | `/remove 2` |
| `/volume [1-100]` | Показать или изменить громкость | `/volume 80` |
| `/seek <position>` | Перемотка (в секундах или mm:ss) | `/seek 1:30` |
| `/repeat_one` | Переключить повтор текущего трека | `/repeat_one` |
| `/repeat_all` | Переключить повтор всей очереди | `/repeat_all` |
| `/join` | Подключить бота к текущему каналу | `/join` |
| `/leave` | Отключить бота от голосового канала | `/leave` |
| `/ping` | Проверить задержку шлюза | `/ping` |
| `/language <lang>` | Переключить язык бота (Русский / English) | `/language Русский` |
| `/lang` | Показать текущий язык сервера | `/lang` |

## Настройка и установка

### 1. Создание приложения в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **New Application**.
2. В разделе **Bot**:
   - Нажмите **Add Bot** (или перейдите во вкладку Bot).
   - Нажмите **Reset Token** и скопируйте полученный токен (не передавайте его никому).
   - В блоке **Privileged Gateway Intents** включите:
     - `Presence Intent`
     - `Server Members Intent`
     - `Message Content Intent`
3. В разделе **OAuth2** -> **URL Generator**:
   - В блоке **Scopes** отметьте: `bot`, `applications.commands`.
   - В блоке **Bot Permissions** отметьте: `Send Messages`, `Embed Links`, `Attach Files`, `Connect`, `Speak`, `Use Voice Activity`.
   - Скопируйте ссылку внизу и откройте её в браузере, чтобы пригласить бота на свой сервер.

### 2. Клонирование репозитория
```bash
git clone https://github.com/Sherik21/DiscordBotPy.git
cd DiscordBotPy
```

### 3. Конфигурация окружения
Скопируйте пример файла конфигурации:
```bash
copy .env.example .env
```
Откройте файл `.env` в любом текстовом редакторе и вставьте ваш токен:
```env
TOKEN=ваш_токен_бота
```

### 4. Запуск

#### Windows (в один клик):
Запустите файл `run.bat`. Скрипт сам создаст виртуальное окружение `.venv`, установит все зависимости и запустит бота.

#### Ручной запуск (любая ОС):
```bash
python -m venv .venv
# Активация окружения (Windows PowerShell):
.\.venv\Scripts\Activate.ps1
# Активация окружения (Linux/macOS):
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```
